# agent-roast-entry

A one-line self-roast of my AI agent — make.fun "Roast Your Own Agent" bounty entry ($5 pool). `main.ts` writes the roast to the directory in MAKEFUN_OUTPUT_DIR (default `/output`).

## Run it
